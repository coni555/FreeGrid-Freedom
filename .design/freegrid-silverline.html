§ 02 · Notes for SwiftUI translation

  1. Numbers must use tabular figures. SwiftUI 等价: .monospacedDigit() 或 .font(.system(.body, design: .monospaced))。所有 stat / today 数字必须等宽防跳动。
  2. Hero 数字 weight 100 thin. iOS 上 SF Pro Display 最细是 ultralight (100)。用 .system(size: 124, weight: .ultraLight)。Letter spacing -0.06em ≈ .tracking(-7)。
  3. Freedom Grid 必须画完整 1825 cells. 这是核心 reframe: 用户看到的是"还有多少未来未点亮"而不只是"我攒了多少"。用 LazyVGrid + 1825 ForEach。已点亮 fill steel, 未点亮 fill mist。
  4. 当前格(第 85 格)呼吸动画. scale 1.0 ↔ 0.85 + opacity 1.0 ↔ 0.6,周期 2.4s。比 v2 暗色版温和得多。
  5. 无阴影,纯描边按钮. primary 按钮是 filled ink 底 + paper 字; secondary 是 stroke 1pt ink + transparent 底。绝不用 shadow / blur。
  6. Kicker 标签全用 mono + uppercase + tracking 0.14em. JetBrains Mono → iOS 没有对应字体, 用 .system(.caption, design: .monospaced) 加 .tracking(1.5)。
  7. 仅一个 italic serif accent: 品牌词 "Silverline" 用 Instrument Serif italic + steel 色。SwiftUI 等价: .font(.system(.title3, design: .serif).italic()) + .foregroundStyle(.steel)。一个屏幕最多出现 1-2 次,不滥用。
  8. Tab bar 用 mono labels + outlined SF symbol. 不要 filled, 不要 SF systemBlue tint。Active 用上方一个 6pt steel dot 标识,不是字体变粗。
  9. 背景纯色无渐变. 主背景 paper, phone safe area 也是 paper。不要 ultraThinMaterial / glass(那是 v2 暗色金库的招式,会和银白冲突)。
  10. 所有 corner radius 1-2pt. grid cells radius 1pt, buttons 100pt (full pill)。除按钮外几乎不用圆角——线条极简的关键。
