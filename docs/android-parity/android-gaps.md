## 可以直接复用的部分

`lib/app/theme/freegrid_theme.dart`、`app/platform/freegrid_platform.dart`、Geist 资产、独立 life_grid/meteor_layer/simulation_grid_demo 等组件，以及已有导出分享、文件选择和主题测试。复用前以最新规格核对结果，不要求与 Swift 文件一一对应。

## 值得局部重建的边界

- `dashboard_shell.dart` 约 4,228 行，含多个页面、表单和写入。按 Dashboard/Assets/Transactions/History/Settings/Guide 拆，不为拆文件强行新增大量接口层。
- 核心摘要、日历计划、交易影响进入纯逻辑层；从同一个输入快照生成结果。
- 数据修改进入独立写入边界；页面不自己拼整份快照再覆盖保存。
- 备份编解码和校验分离；保留所有当前字段，导入前后都能验证。

## 扫描发现的冲突与处理

1. **schema 4 说法过时/不适用**：以当前 iOS `ImportValidator` 常量和实际导出为准；不要继续传播补丁注释中的断言。
2. **“无损保留”不成立于完整操作链**：即使 fixed_expenses 能一次解码→编码，普通新增记录还会省略它。本轮将其视为需修问题，不作为可复用保证。
3. **日历约定与实现不符**：Android AGENTS 禁止裸用 difference 计算自然日，当前 Math 仍这样做。纳入回归而非复制旧实现。
4. **种子账本回落**：当前代码把缺数据和损坏数据都送入演示数据；不作为新用户体验要求。
5. **文档版本不是发布证据**：本轮不核查 GitHub 下载 APK 的二进制内容；Android 未提交补丁不计作线上功能。

未提交代码不应直接删除、覆盖或混入新功能提交。开发开始先确认归属并保存独立快照，选择显式带入或按当前格式替代。
